Padrões Cross-Service (ver doc-arq-cross-service.md)
🔸 Snapshot (imutável na criação)
open_games → field_snapshot, organizer_snapshot
matches → field_snapshot, team_a/b_snapshot
reservations → booker_snapshot
match_proposals → field_snapshot
🔷 Projeção Local (via eventos RabbitMQ)
matchmaking → team_summaries (team + ranking events)
open-game → player_summaries (identity + social events)
gamification → player_identities (identity events)
notification → user_tokens (identity events)
🔹 BFF Aggregation (telas complexas)
Perfil completo do jogador (identity + social + gamification)
Detalhes de partida (game + team + field)
Cache Redis 5–15 min para queries frequentes
🔴 Sync + Circuit Breaker (crítico)
Verificação de auth token (identity-service guard)
Processamento de pagamento (v2)
Timeout: 500ms · Fallback: erro controlado
